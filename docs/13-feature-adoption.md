# 13 · 从 102 个露营插件里，我们该抄什么、不该抄什么

依据：[docs/12](12-camping-addons-landscape.md) 的生态调研（102 个插件，头部 4 个过 5K 下载）。
判断标准只有一条：**能不能在"中文客户端 + spellID 判定 + 双版本"这套地基上做得更稳**。

## 一、立刻采纳（低成本、高收益）

| # | 功能 | 来源 | 我们的做法 | 成本 |
| --- | --- | --- | --- | --- |
| 1 | **战斗中隐藏整个面板** | Camping Kit | `PLAYER_REGEN_DISABLED` 隐藏、`PLAYER_REGEN_ENABLED` 恢复；露营本来就只能在战斗外做 | 半小时 |
| 2 | 物件行标注"能不能放"的三种态 | Camping Companion | 已有：可用 / 需要营火 / 冷却；补上"缺材料"态（`!`） | 1 小时 |
| 3 | 共享冷却只显示一次 | Camping Companion（唯一做对的） | 已完成（`强化休息 1229451`），保持 | 0 |
| 4 | 面板底部版本号 | 通用做法 | 已完成（0.11.1） | 0 |
| 5 | **按 spellID 判定，名字兜底** | 我们独有 | 已完成，且是最大差异化 | 0 |
| 6 | 一键打开对应专业窗口 | Camping Kit | 物件行右键或小按钮 → `C_TradeSkillUI.OpenTradeSkill` | 1–2 小时 |

## 二、值得做，但要先补数据（中等成本）

| # | 功能 | 来源 | 前置条件 |
| --- | --- | --- | --- |
| 7 | 设施手册（每件给什么 buff、要多少技能、蓝图哪掉） | Happy Camper Handbook / Camp Planner | `docs/11` 的设施表补 itemID 与 buff spellID |
| 8 | 六态 buff 面板（已有 / 在营地没吃到 / 被职业 buff 覆盖 / 我能放 / 队友能放 / 缺） | Camping Companion | 需要 buff spellID 表 + 职业 buff 对照 |
| 9 | 小队"谁放什么"指派 | Happy Camper Group | 已有 AZKIT 同步雏形，需加"目标 buff"协商 |
| 10 | 营火容量 3/5/10 与"还差几个" | Camp Planner / Ark Camp | 需识别营火等级（工具包 itemID 已知 279981） |
| 11 | 缺料购物清单（可复制） | Camping Companion | 需要配方材料表 |

## 三、明确不做（超范围或踩线）

| 功能 | 来源 | 原因 |
| --- | --- | --- |
| 地图上共享别人的营火位置 | Happy Camper / Camping Kit | 需要隐藏频道广播 + 长期维护位置库；隐私与合规风险高，且我们默认关闭才安全 |
| 营地 BGM、音色包、合奏 | Hearthsong / Happy Camper | 体积与版权，与"工具"定位无关 |
| 篝火 RP 故事 / 过场动画 | Campfire Tales / Improved Forever | 娱乐向，非效率工具 |
| 复制 Happy Camper 的代码/美术/文案 | — | **许可证：保留所有权利，禁止复制、修改、再分发**。只参考信息架构（Camp 页 / Group 页 / Handbook 三段式） |
| 自动坐下/自动吃食物 | Camping Companion 的 Rest 按钮 | 涉及受保护动作与自动化边界，只做"提示"，不做"代做" |

## 四、差异化护城河（我们已经有、别人没有）

1. **spellID 判定**：`1229739 温馨营火` / `1283391 营火在附近` / `1229451 强化休息` / `1229741 露营增益`。
   生态里唯一做共享 CD 的 Camping Companion 死在"只支持英文客户端"，我们天生不受语言影响。
2. **双客户端**：`120105` + `16001` 同包，头部插件全部只发 `1.60.1`。
3. **共享冷却语义正确**：读 debuff，不猜物品 CD。
4. **可被 Agent 调参**：`Profile.lua` + `/ak export`，生态里没有第二家。

## 五、下一步（按这个顺序）

1. 战斗中隐藏（本文 #1）——立刻做；
2. 缺材料态（#2）——需要"配方材料"数据，先用"背包里有没有"近似；
3. 专业窗口直达（#6）——按物品→专业的映射表，先支持烹饪/制皮/急救三种；
4. 等 `docs/11` 补齐 itemID 后再做手册与六态面板。

## 六、许可红线（写给自己看）

- Happy Camper：**ARR**，不可复制代码/素材/文案；
- 其余多数未标注，默认按"全部权利保留"处理；
- 我们可以参考的是**信息架构与交互模式**（三段式页面、状态色、按钮位置），实现必须自己写。
