# AzerothCamp · 露营管理 v1.0.0

《魔兽世界：无限》（WoW Forever）的露营助手：看得见库存、算得清冷却、管得住小队重复放置。

- 客户端：**仅《魔兽世界：无限》1.60.1**（Interface `16001`）——正式服没有露营系统，本插件不上架正式服
- 语言：**简体中文 / 繁體中文 / English**，跟随游戏语言
- 作者：DSH · 许可：MIT

## 功能

| 功能 | 说明 |
| --- | --- |
| 营火材料 | 显示背包里的营火工具包数量（基础/熟练/专家），没有时显示燧石和火绒；点击即用，有木柴时可直接制造 |
| 帐篷 | 资深冒险者的探险帐篷（+20% 经验）与营地帐篷（+5%）分行显示，各自独立判定 |
| 营地制品 | 按 **itemID** 识别 12 个专业的营地制品，显示数量与效果，并给出「建议放」去重建议 |
| 共享冷却 | 读取 `强化休息` debuff（所有营地制品共享 1 小时），一行显示，不再逐件报 CD |
| 营火容量 | 自己放营火后记录等级（3/5/10 格），队友装了本插件时同步取最大值 |
| 小队同步 | `AZKIT` 前缀广播「我能放什么、冷却还剩多久」，面板列出队友状态 |
| 收纳 | 面板可拖动、可折叠（只向下生长）、战斗中自动隐藏 |
| 版本核对 | 面板底部显示版本号，`/reload` 即更新 |

## 安装

把 `AzerothCamp` 文件夹解压到：

```
World of Warcraft\_forever_\Interface\AddOns\AzerothCamp\
```

重启客户端（或 `/reload`），在插件列表中启用 **AzerothCamp**。

> 若同时安装了 **AzerothKit**，本插件会自动让位（不重复加载面板），功能由套件提供。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/ac camp` | 扫描背包/光环，输出营火、帐篷、营地制品状态 |
| `/ac group` | 广播并打印小队露营状态 |
| `/ac errors` | 查看最近记录的报错 |
| `/ac clearerrors` | 清空报错记录 |

## 已知限制

- 队友未安装本插件时，看不到他的物品与冷却（游戏不向插件暴露他人背包）；
- 营火容量依赖「谁放的营火」：自己放的能记住等级，别人放且未装插件时显示未知；
- 露营只能在战斗外进行，因此战斗中面板会自动隐藏。

## 反馈

报错请附：`/ac errors` 的输出、游戏语言、客户端版本（面板底部版本号）。
